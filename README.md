# Portafolio de Pruebas QA - SauceDemo

¡Hola! Soy **Vincent Leonardo Arias**, estudiante de Ingeniería en Sistemas Computacionales.

Este repositorio contiene la documentación y ejecución de pruebas funcionales para la plataforma de e-commerce **SauceDemo** (https://www.saucedemo.com/).

---

## Estructura de la Documentación

Puedes consultar los entregables del proyecto en los siguientes enlaces:

* **[Plan de Pruebas (Test Plan)](docs/Test_Plan.md):** Definición del alcance, tipos de prueba y entorno.
* **[Matriz de Casos de Prueba (Test Cases)](docs/Test_Cases_SauceDemo.xlsx):** Casos de prueba ejecutados (Login, Carrito y Checkout).
* **[Colección de Pruebas API (Postman)](docs/test/SauceDemo_API_Tests.postman_collection.json):** Pruebas de integración HTTP (GET/POST) con validaciones de código de estado (200 OK y 201 Created).
* **[Pruebas con bugs] (docs/Bug_Report_SauceDemo):** Casos en los que se dio a conocer mas a fondo del codigo o incluso mejor adaptandome.

---

### Herramientas y Metodologías
* **Tipos de Pruebas:** Pruebas Funcionales, Smoke Testing, Negativas y Exploratorias.
* **Técnicas:** Casos de prueba Black Box, Criterios de Aceptación, Bug Lifecycle.
* **Gestión de Datos:** SQL básico y análisis en Excel.
